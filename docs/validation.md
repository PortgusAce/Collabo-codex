- 中文路径、UTF-8/UTF-16/GB18030、文本分页。
- DOCX 正文/表格、PPTX 文字/备注、XLSX 表格提取。

项目创建与发送消息使用模拟客户端验证路由，不会为了测试在用户侧创建聊天或启动模型工作。GitHub Actions 配置了 Windows/Python 3.12 测试，具体在线结果以仓库运行记录为准。

## 本机验收与边界

2026-10-28，Windows 本机验证结果：18 项测试通过，`pip check` 通过；配置窗口正常加载，密钥框遮罩生效；真实网关发现 11 个工具，允许目录、本地项目和桌面聊天列表调用成功；官方 Tunnel 安装校验及连接成功，运行/健康/就绪均为 true。未进行普通 Chat 端到端调用，也未实发新建/续发任务。

本地验证分三层：

1. Python 测试、配置窗口加载、依赖一致性。
2. 已登录桌面上的真实只读项目/聊天调用，以及官方 Tunnel 的运行、健康和就绪状态。
3. 用户从普通 Chat 选择插件后实际调用；再用用户明确授权的真实任务验证创建、续发和产物读取。

第二层通过不能代替第三层通过。若客户端尚未添加插件、工具尚未被外部发现，不能声称普通 Chat 到本机的端到端验收已经完成。实际创建后的 UI 分组、执行与审批也需要第三层验证。

文件转换保留可提取文字和表格，不是视觉版式保真服务，不提供 OCR。纯文件 MCP 可在其他 Python 系统使用；图形配置工具、DPAPI 和本机 Tunnel 自动安装当前面向 Windows。
